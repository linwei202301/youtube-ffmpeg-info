隐私政策

本政策说明 YOUTUBE FFMPEG 如何处理管理员交给工作台的资料，以及通过 YouTube API 服务取得的频道资料。

使用哪些资料

管理员提供影片、播放顺序、直播主题、时长和可见性。连接 Google 后，工作台读取获授权频道的串流与直播场次资料，包括场次识别码、开始时间、收流状态及健康度，用于排程、推流和显示状态。

资料保存在哪里

播放列表、上传的原片、串流密钥、离线授权凭据和排程保存在管理员的服务器。管理网页使用会话 Cookie 维持登录。公开说明页由 GitHub Pages 托管。访问说明页时，浏览器会向 GitHub 请求页面，GitHub 会为安全目的记录访问者的 IP 地址。GitHub 隐私声明

何时传给 YouTube

管理员启用场次管理后，工作台向 Google 和 YouTube 发送直播配置和必要的授权请求。推流期间，所选影片的音视频会传给 YouTube。观看权限取决于管理员为该场直播设置的可见性。

工作台按 Google API 服务用户数据政策及其有限使用要求处理 Google 用户数据。资料用于管理员启用的直播功能，不出售，也不用于广告。Google API 服务用户数据政策 · Google 隐私政策

撤销授权或删除资料

管理员可在 Google 账号的第三方连接中撤销授权。管理员可在工作台移除片单和原片，在 YouTube Studio 管理已在 YouTube 保存的直播。如需删除服务器上保存的授权凭据及相关频道资料，可通过 Google 授权页列出的应用支持邮箱联系管理员。
